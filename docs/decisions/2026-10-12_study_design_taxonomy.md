# Decision: 文献の分類(タグ)を「研究デザイン」の9分類にする

- Date: 2026-10-12
- Status: タグ付けは完了(DB)。サイトの表示は未反映(下記「表示」を別途検証してから反映する)
- 置き換えるもの: `2026-09-23_fixed_tag_taxonomy.md` の7分類(症例報告/臨床研究/基礎研究/総説/ガイドライン/論説/レター)

## きっかけ

公開文献の44%(8,527件)にタグが付いていなかった。タグは PubMed の出版タイプから機械的に決めており、
普通の原著論文(出版タイプが "Journal Article" のみ)は決まらない。また「臨床研究」が広すぎた。

## 分類(1論文に1つ)

| 大分類 | 分類 | 内容 |
|---|---|---|
| 臨床 | SR・MA | システマティックレビュー、メタ解析、スコーピングレビュー |
| 臨床 | RCT | ランダム化比較試験 |
| 臨床 | 非ランダム化試験 | 第I〜III相、単群試験など、ランダム化しない前向きの臨床試験 |
| 臨床 | 観察研究 | コホート、症例対照、横断、疫学・登録、診断精度、予後・バイオマーカー、症例数の多い治療成績、ヒトの遺伝関連 |
| 臨床 | 症例報告・集積 | 1例〜少数例の報告(文献的考察を加えたものを含む) |
| 臨床 | 総説 | ナラティブ・概説(系統的な方法を使わないもの) |
| 臨床 | ガイドライン・コンセンサス | ガイドライン、コンセンサス声明 |
| 臨床 | その他 | 論説、レター、コメント、ニュース、書籍の章、歴史・伝記、動画など |
| 基礎 | 基礎・トランスレーショナル | 細胞・動物・分子・ゲノムなど、機構や生物学が目的の研究 |

基礎・トランスレーショナル以外はすべて臨床として扱う(画面の大分類。`scripts/study_design.py` の `GROUPS`)。

## 決め方

1. PubMed の出版タイプで確実に決まるもの(SR・MA、ガイドライン、RCT、非ランダム化試験、観察研究、その他)は、それを使う。
   優先順: SR・MA > ガイドライン > RCT > 非ランダム化試験 > 症例報告 > 総説 > 観察研究 > その他。
   症例報告と総説の両方が付く論文(約850件)は症例報告にする。
2. それ以外(出版タイプが症例報告・総説のものと、出版タイプで決まらない原著論文)は、AI(haiku 5.5 / **medium**。分類は effort を medium にする指示 2026-10-12)が題名・抄録から決める。
   AIが症例報告・総説の出版タイプと食い違ったときは、確信度が高・中ならAIを採る。低ければ出版タイプを採る。
   出版タイプで決まらないものは、確信度が低くてもAIの判定を使う。
3. 個別の上書き表(`data/reference/classification/tag_overrides.tsv`)が、すべてに優先する。
4. 以後の新しい文献は、`process_batch.py` の判定時に同じ分類をAIに付けさせる(`study_design`)。

## 症例集積の基準(2026-10-13 決定)

症例報告・集積と観察研究の境目は、症例数ではなく内容で決める。**記述的な症例集積は、例数によらず「症例報告・集積」**
(患者の臨床経過・所見を述べるもので、仮説・比較群・統計解析がないもの)。**観察研究**は、問いと定量的な解析
(率、群間比較、生存・リスク解析、関連)があるもの。当初の「約10例」の目安はやめた(PMID 38778412 の14例の後ろ向き集積は症例集積)。
AI の分類をこの基準で、境目の14,949件(症例報告・集積と観察研究と判定されていたもの)について再判定した(1,210件が変わった)。

## 決めていないこと・限界

- 基礎とみなす範囲(ヒトの検体の分子解析など)はAIの判断に依存する。
- 出版タイプ(RCT、非ランダム化試験など)は、PubMed の付与をそのまま信用している。
- サイトのタグ(`data/papers/` の `tags`)は、まだ旧7分類のまま。DBのタグを反映するには、画面の絞り込み(基礎/臨床の2段階)
  の対応が必要なため、別途行う。反映は `retag_categories.py --site-papers` で、サイトのタグがDBの旧タグと一致する場合だけ更新する。
