# 検索結果のダウンロード(CSV / RIS)と、ご利用にあたっての注意書き

決定日: 2026-11-04

## 決めたこと
- 検索語・区分・研究デザイン・属性・IFで絞った結果を、**現在の並び順の上位100件まで**、CSV または RIS でダウンロードできるようにする。100件を超える場合は、並び順の上位100件だけを出力する(例: 発行年の新しい順なら、最新の100件)。
- **CSV**: UTF-8(BOMつき。Excel で日本語が文字化けしない)。**1行目は検索式**(キーワード・区分・研究デザイン・属性・IF・並び順・ヒット件数・出力件数・日付・サイト)、2行目が列名、3行目からデータ。列は PMID、DOI、収載誌、発行年、タイトル(原題)、抄録(原文)。
- **RIS**: 1論文1レコード(TY・TI・AU・T2・PY・DO・AN(PMID)・UR(PubMed)・AB・N1)。検索式は、各レコードの N1(注記)に入れる(RIS には、先頭に書くコメントの決まりがなく、先頭に別の行を置くと、取り込みに失敗するソフトがあるため)。
- 抄録は、カードを開くときと同じ `search/abstract/<id>.json` から、上位100件分だけを読む(追加のデータファイルは作らない)。DOI・著者は、詳細(`search/details/`)から、必要な分だけを先に読む。書き出しはすべてブラウザの中で行い、サーバーには送らない。
- 全件の読み込みが終わるまでは、ボタンを出さない。
- 100件を上限にしたのは、本サイトの目的が文献紹介であり、検索結果の大量のダウンロードを想定していないため。

## サイト紹介の冒頭への追記(`data/site.json` の `usage` / `usage_ja`)
次の趣旨を、ヘッダーの説明の直下に表示する。
1. 本サイトは、文献の情報を把握しやすくする文献紹介が目的で、大量のダウンロードは想定していない(ダウンロードは上位100件まで)。
2. 要約・分類・属性・和訳は、AIを用いて作成した参考情報で、研究などへの利用を含め、データの正確性・完全性は保証できない。
3. 有用と思われる文献は、必ず原著(原本)を確認してもらう。

## 確認
`npm run check:export`(実ブラウザ。1行目の検索式、列、上位100件と並び順、抄録が原文と一致、BOM、RIS の項目、絞り込み・並び替えの反映、100件以下、英語ページ、注意書き)。

## 追記(2026-11-05): チェックした文献だけのダウンロード
- 各カードの右上にチェックボックスを置き、チェックした文献だけを、CSV または RIS でダウンロードできるようにした。上限は同じく100件(100件に達すると、選んでいないチェックボックスは使えなくなり、1件外すと選べる)。
- 選択は、絞り込み・検索・並び替えを変えても残る(ページを読み直すと消える。保存しない)。「表示中の文献を選択」(画面に出ているカードを、上限まで選ぶ)と「選択を解除」がある。
- 画面の下に固定のバーを出し、選択件数と、ダウンロードのボタンを置く。
- 出力の並びは、現在の並び順。CSV の1行目は「検索式: 選択した文献: n / 日付 / サイト」。RIS は各レコードの N1 に同じ内容を入れる。列と項目は、検索結果のダウンロードと同じ。
- 全件の読み込みが終わるまでは、チェックボックスを出さない。
