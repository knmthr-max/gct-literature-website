# Documentation

- `operations/`: スクリプトと定期更新の取扱説明書
- `data_dictionary/`: 公開データ・作業用DB・JIF参照データなどのfield定義(`README.md` に現行/旧世代の別)
- `architecture/`: 現行の構成は `current_architecture.md`(旧世代のTSV設計は記録として残す)
- `decisions/`: 設計判断と採用理由
- `history/`: データ更新・migration・version履歴

各program固有の実行方法は、codeと同じディレクトリのREADMEを正本とします。
